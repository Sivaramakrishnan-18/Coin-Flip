Host on GitHub Pages in 3 Steps

1

Create a GitHub repository

Go to github.com/new, name it (e.g. coin-flip), and set it to Public.

2

Save this code as index.html

Upload or commit this single file into the root folder of your repository named exactly index.html.

3

Enable GitHub Pages

Go to repository Settings → Pages. Under Build and deployment, set Source to Deploy from a branch and select main / (root) & save. Your live URL will appear in ~1 minute!
